# 0002. Any signed-in member can set the date

- Status: Accepted
- Date: 2026-11-14

## Context

The date is for the players, not only the DM.

## Decision

Any signed-in member of the estate, including a reader, can set the calendar anchor or re-anchor the current turn. Anonymous visitors and signed-in users who are not members cannot. Every date change is journaled with who made it.

## Consequences

Readers still cannot take a turn, issue orders, or change money, rooms, or the turn counter.
