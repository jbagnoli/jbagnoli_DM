# 0010. People tab layout

- Status: Accepted
- Date: 2026-11-15

## Context

The People tab used a tall card for every person.

## Decision

Each person is one line: name and tags on the left, role or description on the right, action buttons at the far right. On a narrow screen the line stacks. The controls stay real buttons.

## Consequences

The page stays usable on a phone and still supports adding, editing, replacing, and removing a person.
