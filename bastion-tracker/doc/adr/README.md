# Decision records

A design change to the Bastion Tracker gets a new file in this folder before or with the change. Future changes must add an ADR. Do not rewrite an accepted record; add a new one if a decision changes.

Number files `0001-short-name.md` and add a line to the index below.

## Template

Copy this shape:

```
# NNNN. Title

- Status: Accepted
- Date: YYYY-MM-DD

## Context

What problem or request this answers.

## Decision

What we will do.

## Consequences

What changes for the table, and what we are not doing.
```
